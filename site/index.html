🧠 LocalMind
Features Quickstart Hardware GitHub ↗

Your private AI.
On your hardware.

LocalMind auto-detects your machine, picks the right model, and gives you chat, grounded RAG over your own documents, a tool-using agent, long-term memory, a web UI, and an OpenAI-compatible API. Zero API keys. Zero cloud calls.

terminal 
pip install -r requirements.txt
python main.py doctor      # what can my machine run?
python main.py pull        # fetch the auto-picked model
python main.py ui          # web UI at http://127.0.0.1:7860

No GPU? No problem — python scripts/mock_ollama.py runs the whole stack with a fake backend so you can try it before downloading any weights.

Everything in one entrypoint

💬 Chat

Streaming terminal & Gradio chat with rolling conversation summary and a durable fact store that resurfaces old details on demand.

📚 Hybrid RAG

Dense vectors + BM25 fused with Reciprocal Rank Fusion, cross-encoder reranking and query expansion. Answers cite your sources.

🛠️ Agent

A ReAct loop with Python, shell, filesystem, calc and memory tools — jailed to ./workspace with a destructive-command denylist.

🔌 OpenAI API

/v1/chat/completions with streaming SSE. Point Continue.dev, Cursor, LangChain or curl at localhost:8000.

🗂️ Ingest anything

PDF, DOCX, HTML, Markdown and code → chunked into a numpy-backed index. No database, no daemon, survives restarts.

🧱 Backend-agnostic

Same code runs on Ollama, llama.cpp or Transformers — swap backend in data/config.json.

Quickstart

bash 
git clone https://github.com/prayerdome0/Ai-health.git
cd Ai-health
pip install -r requirements.txt

python main.py doctor            # hardware report + setup advice
curl -fsSL https://ollama.com/install.sh | sh   # if doctor says Ollama missing
python main.py pull              # download the model auto-picked for your hardware

python main.py chat              # terminal chat
python main.py ui                # web UI
python main.py ingest ~/Documents
python main.py ask "what's our rollback procedure?"
python main.py agent "count lines of python in ./workspace and plot a histogram"
python main.py serve             # OpenAI-compatible API on :8000/v1
any OpenAI client 
curl http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"local-rag","messages":[{"role":"user","content":"summarize my docs on auth"}]}'
