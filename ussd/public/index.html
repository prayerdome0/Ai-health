How to use

1. Press Call *123# to open a session.
2. Type replies with the keypad (use * for menus, type digits for answers).
3. Press Send after each reply.
4. END screens close the call — dial again to restart.

Try: 1 to register → type a name → choose a 4-digit PIN, then 2 to check your account and 3 to place an order.
